5-1. 한 달치 Word 원문 불러오기

.docx 파일 선택
앞의 extract_missa.py로 만든 Word 파일을 선택하세요. 새 버전은 날짜마다 ===DATE:YYYYMMDD=== 표시를 넣어 자동 분리가 더 정확합니다.
아직 Word 원문을 읽지 않았습니다.

5-2. 발행용 대제목 · 소제목

CBCK 원문의 전례명과 실제 발행 제목이 다를 수 있으므로, 최종 HTML 제목은 이 목록을 우선합니다. 앞 단계 전례력으로 자동 작성한 뒤 필요하면 직접 고치세요.
아직 발행용 제목을 확인하지 않았습니다.
연중 → 제1독서·복음·묵상기념/축일 → 초대문 + 제1독서·복음·묵상주일/대축일 → 초대문 + 제1독서·화답송·제2독서·복음·묵상

5-3. 티스토리 이미지 태그 연결

이미지는 티스토리가 실제 업로드하면서 만든 [##_Image|kage@..._##] 토큰이어야 화면에 나옵니다. 정상 발행된 글의 HTML을 붙이면 역할별 이미지 태그를 자동 추출합니다. 기존 kage URL·originWidth·originHeight·filename 등은 그대로 보존하고 alt만 현재 제목에 맞춥니다.
아직 이미지 태그를 추출하지 않았습니다.
이미지 태그를 직접 넣거나 확인하기

5-4. 공통 HTML 설정

자동 적용하는 3종 규칙
① 연중: 대표이미지 → 광고 → 제1독서 → 복음 → 묵상
② 기념/축일: 대표이미지 → 초대문 → 광고 → 제1독서 → 복음 → 묵상
③ 주일/대축일: 대표이미지 → 초대문 → 광고 → 제1독서 → 화답송 → 제2독서 → 복음 → 묵상

모든 독서·복음 원문은 삭제/요약하지 않고, 절 번호는 분홍색, 말씀 출처는 회색, 응답은 검정 굵게, 묵상 필자는 초록색 굵게 변환합니다.
